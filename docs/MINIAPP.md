# Кабинет Telegram: запуск и ограничения

В каталоге miniapp находится адаптивный интерфейс: главная страница с таймером, календарь, начисления и графики за шесть недель, раздел проверки. Тёмная и светлая темы поддерживаются без внешних библиотек интерфейса.

## Демонстрация

Открой index.html в браузере либо запусти локальный HTTP-сервер внутри каталога miniapp. В обычном браузере отображаются только вымышленные значения. В серверную базу демонстрация не обращается.

## Настоящая авторизация

Приватный API реализован в miniapp_server.py. Для каждой операции проверяются HMAC-SHA256 подпись Telegram initData, совпадение Telegram ID с единственным владельцем и время выдачи данных (не старше одного часа). Параметры из JavaScript без подписи не используются для идентификации.

## Развёртывание

1. Запускай сервер только от отдельного непривилегированного пользователя.
2. По умолчанию Python HTTP-сервер слушает 127.0.0.1:8765 и не публикуется в интернет.
3. Пример запуска — deploy/workshift-miniapp.service, с отдельным закрытым env-файлом токена и каталогом SQLite.
4. Режим записи через Mini App по умолчанию запрещён, MINIAPP_ENABLE_WRITES=0. Основные отметки продолжают работать через Telegram-бота.
5. Для реальной кнопки открытия Mini App нужен отдельный домен и HTTPS, прокси только с безопасными путями, проверкой доступов и тестами защиты от повторных запросов. Не перенастраивай действующий общий прокси другого приложения без отдельного решения.
6. Проверь раздельно доступ к статическим файлам, отказ API без подписи и успешный запрос только от владельца.

## Приватность и отсутствие интернета

Никакие личные смены не встроены в публичный HTML, CSS или JavaScript. Данные отображаются только после авторизации. Факт прихода/ухода нельзя подтверждать без сети. Если пользователь создаёт офлайн-черновик, он хранится локально на устройстве и не прибавляется к зарплате; после восстановления сети нужно подтвердить время отдельным действием.

## Проверки

Запусти тесты мини-кабинета командой:

    python -m unittest test_miniapp.py -v

Проверь JavaScript в современном Node.js:

    node --check miniapp/app.js

Обычный Telegram-бот остаётся резервным интерфейсом и не зависит от графического кабинета.
## Защита запросов и целостность действий

Чтение состояния открывает уже существующую SQLite через `mode=ro`, `query_only` и согласованный снимок. Оно не создаёт таблицы и не изменяет записи. Тело API — только JSON, не более 8 КБ; неоднозначный Content-Length и Transfer-Encoding отклоняются. Соединения ограничены по времени и количеству, а окно rate limit для подписанного владельца отделено от ошибочных запросов.

Перед отдельным HTTPS-развёртыванием нужно задать `MINIAPP_PUBLIC_ORIGIN` равным точному origin, например `https://example.com`. При наличии заголовка Origin он обязан совпадать; cross-site-запросы запрещены. Авторизация не опирается на cookies. Не удаляй проверку подписи и владельца ради устранения ошибки Origin.

В `miniapp_actions.py` запись охвачена одной блокирующей транзакцией: проверка ожидаемой смены/перерыва, исходная бизнес-операция, журнал и сохранённый ответ. Повтор того же nonce возвращает тот же ответ. Новый запрос со старым идентификатором смены или перерыва отклоняется. При ошибке откатывается вся операция. Эти проверки не являются основанием автоматически включать запись на действующем сервере.

CSP разрешает встраивание только в собственный origin и Telegram Web; произвольные внешние фреймы не разрешены. Личные данные не кэшируются, тела запросов и заголовки авторизации не пишутся в журнал. За TLS, размер входящих запросов и внешнюю поверхность отвечает отдельно согласованный прокси; исходный HTTP-сервер остаётся на loopback.

## Проверка клиентом перед включением записи

На настоящем клиенте Telegram проверь открытие с меню владельца, работу часов и календаря, смену темы, экранную клавиатуру и безопасные отступы. Отдельно проверь чужой аккаунт, повторное открытие после истечения сессии и восстановление сети. Серверные автотесты и браузер с вымышленным SDK не подтверждают эти клиентские сценарии. До завершения этой проверки оставляй `MINIAPP_ENABLE_WRITES=0`: кнопка кабинета возвращает к отметкам в чате.
