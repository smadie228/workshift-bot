# Архитектура

~~~mermaid
flowchart TD
    A[Telegram: личный чат] --> B[Bot API: polling]
    B --> C{Проверка владельца}
    C -->|Разрешён| D[Учёт смен и начислений]
    C -->|Отказ| E[Доступ закрыт]
    D --> F[(SQLite WAL)]
    F --> G[Excel-отчёты]
    F --> H[Резервное копирование]
    F --> I[Журнал действий]
~~~

Все события сохраняются в UTC и отображаются по Europe/Moscow. Ночная смена относится к дате прихода. Офисный табель, импорт и личные отметки разделены. Новая почасовая ставка не изменяет старые начисления. Excel — производный отчёт, а не источник истины.
