# Безопасность

- Команды выполняются только владельцем после одноразовой привязки Telegram ID.
- Не храните токены и секреты в Git; используйте закрытые переменные окружения и права файлов 0600.
- SQLite WAL, транзакции, журнал действий, проверка пересечений и времени окончания смены.
- Подлинные документы, фотографии и история старого Git не должны попадать в публичный репозиторий.
- Офисные XLSX проверяются по размеру, макросам и внешним ссылкам. Часы не перезаписываются без проверки.
- Локальное резервное копирование не защищает от полного отказа VPS: нужны независимые зашифрованные копии и пробное восстановление.
- Обычный Telegram-бот не обеспечивает сквозного шифрования. Не отправляйте пароли, реквизиты и документы личности.
