# Развёртывание Linux-службы

1. Создайте отдельного системного пользователя и каталог данных (0700).
2. Разместите код в каталоге приложения и установите зависимости в отдельное Python venv.
3. Создайте закрытый env-файл вне Git с TELEGRAM_BOT_TOKEN (0600).
4. Сгенерируйте одноразовый код pair.code с правами 0600.
5. Проверьте пути и ограничения в unit-файлах папки deploy/.
6. Активируйте systemd-службу и таймер резервного копирования.
7. Проверьте логи без секретов, права доступа и восстановление на отдельной тестовой базе.

Не запускайте два polling-процесса с одним токеном одновременно.
